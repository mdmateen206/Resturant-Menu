# Resturant-Menu
🍽️ Python Restaurant Menu Program

A simple restaurant ordering system built using Python. This console-based application allows customers to view a menu, place orders, add additional items, and receive a final bill amount.

📌 Features
Customer welcome message
Display restaurant menu with prices
Order food items from the menu
Add multiple items to the order
Check item availability
Automatic bill calculation
Simple and beginner-friendly Python code
🛠️ Technologies Used
Python 3
Dictionary Data Structure
Conditional Statements
User Input Handling
Loops
🚀 How It Works
Customer enters their name.
The restaurant menu is displayed.
Customer selects an item.
Customer can add another item if desired.
Total bill is calculated automatically.
Final amount is displayed along with a thank you message.
